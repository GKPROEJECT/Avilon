# Security Policy

## Supported Versions

Security updates are provided for actively maintained versions of AVILON.

Users are encouraged to use the latest available release to ensure they benefit from the most recent security fixes and improvements.

## Reporting a Vulnerability

If you discover a potential security vulnerability in AVILON, please report it responsibly.

**Please do not disclose security vulnerabilities through public GitHub Issues or public discussions.**

Instead, use GitHub's private vulnerability reporting feature available in this repository.

When submitting a report, please include:

- A clear description of the vulnerability.
- The affected AVILON version.
- Steps to reproduce the issue.
- The potential impact.
- Any additional information that may help investigate the issue.

## Response and Disclosure

The AVILON project maintainers will review submitted vulnerability reports and, when appropriate, work on a fix before publicly disclosing the issue.

Please allow reasonable time for investigation and remediation before sharing vulnerability details publicly.

## Responsible Disclosure

We appreciate the efforts of security researchers and users who help improve AVILON's security.

Thank you for helping keep AVILON and its users safe.
