# Avilon Game Library Manager Information

## Summary
Avilon is a game library manager application with a graphical user interface built using Python and Tkinter. It allows users to manage their game collection, including adding games with images, viewing game details, and configuring application settings.

## Structure
- **Root Directory**: Contains main Python scripts, configuration files, and resources
- **build/**: Contains build artifacts generated by PyInstaller
- **dist/**: Contains the compiled executable
- **game_images/**: Stores game images uploaded by users
- **test_images/**: Contains test images for validation testing

## Language & Runtime
**Language**: Python
**Version**: 3.13.x
**Build System**: PyInstaller
**Package Manager**: pip

## Dependencies
**Main Dependencies**:
- Pillow (>=9.0.0): Image processing library
- pywebview (>=4.0.0): Web content rendering

## Build & Installation
```bash
# Install dependencies
pip install -r requirements.txt

# Build executable
python -m PyInstaller Avilon.spec --clean --noconfirm
```

## Application Components
**Main Script**: Avilon_clean.py
**Entry Point**: SplashScreen class initializes the application
**Configuration Files**:
- avilon_config.json: Stores user preferences
- avilon_games.json: Stores game library data

## Resources
**Icons & Images**:
- logo.ico: Application icon used throughout the interface
- game_images/: Directory for storing user-uploaded game images

## Testing
**Test Files**: test_validations.py
**Test Resources**: test_images/ directory with sample images
**Validation Tests**: Image format validation, URL validation for maps

## Packaging
**Spec File**: Avilon.spec
**Build Configuration**:
- Includes logo.ico as a resource
- Creates a windowed application (no console)
- Output executable: dist/Avilon.exe

## Features
- Game library management
- Custom splash screen with animations
- Theme customization
- Game image management
- Map integration
- Startup configuration
